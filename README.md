# WorldQuest
Mod de Project Zomboid (Build 42) que convierte la supervivencia en un juego de
estrategia multijugador: facciones, colonias, diplomacia, comercio, guerra y victoria.

- Diseño y hoja de ruta: [docs/DISENO.md](docs/DISENO.md)
- Plan de prueba multijugador: [docs/PRUEBAS.md](docs/PRUEBAS.md)
- Subir al Workshop: `.\tools\preparar-workshop.ps1`

Opcional: el mod Bandits (id `Bandits2`) le da cuerpo a los colonos.
